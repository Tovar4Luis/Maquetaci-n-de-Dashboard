# Dashboard de Análisis

Este es un dashboard de análisis construido con HTML y Tailwind CSS que muestra estadísticas importantes y gráficos de rendimiento.

## Características

- Visualización de estadísticas clave (KPIs)
- Gráfico de crecimiento de usuarios (comparación 2023 vs 2024)
- Gráfico de ingresos mensuales
- Diseño moderno y limpio usando Tailwind CSS
- Gráficos interactivos usando Chart.js

## Tecnologías Utilizadas

- HTML5
- Tailwind CSS (via CDN)
- Chart.js

## Cómo Ejecutar

1. Clona este repositorio
2. Abre el archivo `index.html` en tu navegador web
3. ¡Listo! No se requiere ninguna instalación adicional ya que usamos CDNs para las dependencias
